Also remove the explicit `{'\n'}` after each `.diff-line` — once `.diff-line` is `display: grid` it is a block-level container and the trailing newline is both redundant and a stray text node in the grid container.
- [x] 1.3 In `web/src/git/DiffHunk.css`:

Move breathing room into the marker column (the `1.25ch` slot already provides this) and/or into row-internal text-cell padding if needed.

- [x] 1.4 Add sticky-left rules under `.diff-hunk-body.wrap-off` for the gutter columns AND the marker column (per Decision 8 in design.md): `.diff-gutter-old { position: sticky; left: 0; z-index: 1 }`, `.diff-gutter-new { position: sticky; left: 3ch; z-index: 1 }` (or whichever exact `left` matches the rendered old-column width), `.diff-line-marker { position: sticky; left: 6ch; z-index: 1 }` (or 2 × old-column width). Keeping the pinned widths defined in `ch` units keeps the offsets consistent across themes.
